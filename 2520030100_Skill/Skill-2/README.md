# OS Skill 2 - Simple Shell

## Aim
To create a simple shell that displays a prompt, reads user input, and exits when the user enters `exit`.

## Description
This project implements a basic shell using C.

The shell:
- Displays the `myshell>` prompt.
- Reads the user input.
- Prints the entered command.
- Continues running until the user enters `exit`.
- Displays `Exiting shell...` before stopping.

## File
- `skill2.c` - C program for the simple shell.

## How to Run

Compile the program:

```bash
gcc skill2.c
